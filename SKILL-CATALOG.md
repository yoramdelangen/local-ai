# Skill catalog

A skill is a prompt/instruction set that tells an agent when and how to do a type of work. It is not a standalone program.

## Ownership and counts

- `skills/`: 66 locally maintained skills plus 9 links into the Caveman submodule.
- `repositories/caveman/skills/`: 22 upstream Caveman skills; 9 are linked from `skills/`, and the rest are discovered from the repository path.
- `repositories/superpowers/skills/`: 15 upstream Superpowers skills, discovered from the repository path.
- The 66 local skills are not copies of either submodule.
- Caveman and Superpowers submodules pin upstream revisions; update with `./install.sh --update-submodules`.
